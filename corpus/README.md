## 三、文本性质与使用注意

1. **繁简混杂**：道藏本、四库本、kanripo 本为**繁体**扫描数字化；殆知阁各本为**简体**整理本。
   《皇极经世》正文建议以**版本甲（道藏本）**为主，版本丙/丁作简体对照。
2. **OCR 讹字**：kanripo/bkkbooks 源自影印 OCR，存在个别讹字
   （如"邵雍"或作"邵堯夫撰"衍"擇/郡"字、道藏卷号标记"而/益/詠/樂/賤/禮/貴"混入卷题行）。
   引用原文前请与影印本核对。
3. **断行**：繁体各卷按影印页行宽断行，诗句/注文偶被拆行；做全文检索或模型语料时
   建议先按标点重排。
4. **托名作品**：《梅花易数》《铁板神数》《梅花诗》皆为后世托名。本库已收《梅花易数》；
   《梅花诗》十首因作者存疑且无可靠公开来源，未收；《铁板神数》系晚出术书，未收。
5. 元数据头部（kanripo 的 `#+` 行、bkkbooks 的 yaml）已在整理时清洗，
   版面页码 `<pb:>`、段落符 `¶`、私用区字符已剔除。

## 四、与本项目的关系

这批语料是"用邵雍思想训练模型"的下一阶段原料，可支撑：

- **击壤集（1500+ 首诗）** → 训练"击壤体"诗歌语言模型（心性论的计算化）；
- **观物内/外篇** → 提取邵雍认识论命题集，构建"观物"命题库；
- **声音律吕卷（道藏本卷19–20）** → 复原十六声×十六音唱和图，实现调研报告 §五设想的
  256 组合编码空间；
- **以运经世编年（卷13–18）** → 与 `huangji/shuju.py` 历史数据集对齐校核。
