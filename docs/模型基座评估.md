## 二、需要什么级别的基座？

| 路线 | 需要的基座 | 判定 |
|---|---|---|
| 从零预训练 | 数十 B token 级通用语料 + 数月算力 | ✗ 不需要（领域语料仅数十万字，差 5 个数量级） |
| **领域继续预训练（CPT）** | 中型底座 + 古文语料 | △ 可选后期项：用 corpus 60 万字做轻量 CPT，先不急 |
| **SFT/LoRA 专项微调** | 7B–14B 中文开源指令底座 | ✓ **推荐路线**（Codex 三步法） |
| 纯 RAG（不训练） | 任意底座 + corpus 检索 | ✓ **必须先做**——它是训练增益的对照基线，也最快可用 |

## 四、何时需要？（决策门槛，避免为训练而训练）

```
现在 ──► 数据阶段（0 算力成本）
          完成 训练规范 50 条 + 500 条审核 SFT 示范 + 100 条隔离测试题
        ──► RAG 基线（半天，本地推理即可）
          基座(7B) + corpus 检索，跑六维评测（新问题迁移/关系一致性/归属/条件变化/边界/来源计算）
        ──► 分岔点（唯一决策门槛）
          若 RAG 版六维达标率 ≥ 目标 → 不训练，直接用 RAG（省下的就是赚的）
          若"概念运用一致性/归属准确性"两项显著掉队 → 启动 QLoRA（按训练规范 §五三步法）
        ──► 训练阶段（本机 A100，7B-QLoRA 单轮约数小时）
          SFT → 盲评 vs RAG 基线 → 缺陷定向扩产 → 复训 → 出对比报告
```

## 五、前置清单（启动训练前的一次性准备）

1. `pip install torch transformers peft trl datasets accelerate`（本机 Python 3.12 兼容；
   torch 选 cu121+ 轮子）；
2. 权重下载：`HF_ENDPOINT=https://hf-mirror.com huggingface-cli download Qwen/Qwen2.5-7B-Instruct`
   （或 ModelScope `modelscope download --model qwen/Qwen2.5-7B-Instruct`），约 15GB；
3. 训练/评测代码走 LLaMA-Factory 或 peft+trl 自写（建议自写小而可控，与本仓库纯 Python 风格一致）；
4. RAG 检索件：corpus 分卷切片 + 简易 BM25/向量检索（先 BM25，繁简归一后建索引）；
5. 与本机其他 GPU 负载协商独占窗口（训练 4–8 小时级）。

## 六、结论

- **需要基座吗？** 需要"一个"：Qwen2.5-7B-Instruct（Apache-2.0）。不需要从零预训练，不需要 70B。
- **现在就要吗？** 权重可以现在下载备好（15GB，镜像可达）；但**训练等数据**——
  规范 50 条 + 500 条审核示范完成之前，任何训练都是无米之炊。
- **先做什么？** RAG 基线（不训练）先行，它是"训练到底增加了什么"的对照组，
  也是 Codex 盲评协议的必要一侧。

**最终裁决（按 §四分岔点）**：
1. **RAG 版在六维隔离测试族上达到满分——按预注册规则，QLoRA 训练暂不启动**。
   "训练增益"假设在当前测试族上无空间；省下的算力成本是真实的。
2. 诚实声明（防过度宣称）：① 12 题是小测试族，满分 ≠ 通用领域满分，扩至 100 题后
   预计仍会出现长尾失败（长篇分析、诗歌鉴赏、跨卷综合）；② 满分是"基座+语料+提示词+
   quote_guard 后处理"整体的成绩，其中引文忠实度主要由后处理器保障；
   ③ 语料在评测轮次间有增补（已如实记录），评测对象是系统整体。
3. **训练重启条件**（预注册）：测试族扩至 ≥100 题且出现某维度 <80%；
   或引入"长篇综合分析"新维度后 RAG 版不达标；或击壤集诗歌生成（M2 之外的新目标）立项——
   届时训练规范已有 31/50 条，SFT 数据管线可立即启动。
4. 下一步重心回到内容侧：规范 31→50、唱和图结构化（M1）、异文率实质统计（M2 前置）。
