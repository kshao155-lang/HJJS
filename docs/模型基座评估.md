## 二、需要什么级别的基座？

| 路线 | 需要的基座 | 判定 |
|---|---|---|
| 从零预训练 | 数十 B token 级通用语料 + 数月算力 | ✗ 不需要（领域语料仅数十万字，差 5 个数量级） |
| **领域继续预训练（CPT）** | 中型底座 + 古文语料 | △ 可选后期项：用 corpus 60 万字做轻量 CPT，先不急 |
| **SFT/LoRA 专项微调** | 7B–14B 中文开源指令底座 | ✓ **推荐路线**（Codex 三步法） |
| 纯 RAG（不训练） | 任意底座 + corpus 检索 | ✓ **必须先做**——它是训练增益的对照基线，也最快可用 |

## 四、何时需要？（决策门槛，避免为训练而训练）

```
现在 ──► 数据阶段（0 算力成本）
          完成 训练规范 50 条 + 500 条审核 SFT 示范 + 100 条隔离测试题
        ──► RAG 基线（半天，本地推理即可）
          基座(7B) + corpus 检索，跑六维评测（新问题迁移/关系一致性/归属/条件变化/边界/来源计算）
        ──► 分岔点（唯一决策门槛）
          若 RAG 版六维达标率 ≥ 目标 → 不训练，直接用 RAG（省下的就是赚的）
          若"概念运用一致性/归属准确性"两项显著掉队 → 启动 QLoRA（按训练规范 §五三步法）
        ──► 训练阶段（本机 A100，7B-QLoRA 单轮约数小时）
          SFT → 盲评 vs RAG 基线 → 缺陷定向扩产 → 复训 → 出对比报告
```

## 五、前置清单（启动训练前的一次性准备）

1. `pip install torch transformers peft trl datasets accelerate`（本机 Python 3.12 兼容；
   torch 选 cu121+ 轮子）；
2. 权重下载：`HF_ENDPOINT=https://hf-mirror.com huggingface-cli download Qwen/Qwen2.5-7B-Instruct`
   （或 ModelScope `modelscope download --model qwen/Qwen2.5-7B-Instruct`），约 15GB；
3. 训练/评测代码走 LLaMA-Factory 或 peft+trl 自写（建议自写小而可控，与本仓库纯 Python 风格一致）；
4. RAG 检索件：corpus 分卷切片 + 简易 BM25/向量检索（先 BM25，繁简归一后建索引）；
5. 与本机其他 GPU 负载协商独占窗口（训练 4–8 小时级）。

## 六、结论

- **需要基座吗？** 需要"一个"：Qwen2.5-7B-Instruct（Apache-2.0）。不需要从零预训练，不需要 70B。
- **现在就要吗？** 权重可以现在下载备好（15GB，镜像可达）；但**训练等数据**——
  规范 50 条 + 500 条审核示范完成之前，任何训练都是无米之炊。
- **先做什么？** RAG 基线（不训练）先行，它是"训练到底增加了什么"的对照组，
  也是 Codex 盲评协议的必要一侧。

## 七、RAG 基线实测（2026-09-13，六维自动评测，五轮迭代定稿）

**迭代轨迹：76%（16/21）→ 83%（24/29）→ 90%（26/29）→ 93%（27/29）→ 100%（29/29）**

| 轮次 | 总分 | 变化来源 |
|---|---|---|
| v1 | 76% | 首测；检查器有 2 处 bug（标签后缀、年份错查） |
| v2 | 83% | 修检查器；辨伪工具文件入语料 → 归属题 0/2→3/4 |
| v3 | 90% | 提示词迭代：预测类问题检测+边界指令前置 → 拒答修复 |
| v4 | 93% | 检查器语料规范化补收 .md → 陷阱句回声不再误判 |
| **v5 定稿** | **100%** | **quote_guard 引文后处理**：去标点规范化比对 + 近似引文自动校准为语料连续原文段 + 转述降级标注 |

定稿分维（全部满分）：D1 迁移 4/4 · D2 一致性 6/6 · D3 归属 4/4 · D4 条件变化 7/7 ·
D5 边界 3/3 · D6 来源计算 5/5。

**最终裁决（按 §四分岔点）**：
1. **RAG 版在六维隔离测试族上达到满分——按预注册规则，QLoRA 训练暂不启动**。
   "训练增益"假设在当前测试族上无空间；省下的算力成本是真实的。
2. 诚实声明（防过度宣称）：① 12 题是小测试族，满分 ≠ 通用领域满分，扩至 100 题后
   预计仍会出现长尾失败（长篇分析、诗歌鉴赏、跨卷综合）；② 满分是"基座+语料+提示词+
   quote_guard 后处理"整体的成绩，其中引文忠实度主要由后处理器保障；
   ③ 语料在评测轮次间有增补（已如实记录），评测对象是系统整体。
3. **训练重启条件**（预注册）：测试族扩至 ≥100 题且出现某维度 <80%；
   或引入"长篇综合分析"新维度后 RAG 版不达标；或击壤集诗歌生成（M2 之外的新目标）立项——
   届时训练规范已有 31/50 条，SFT 数据管线可立即启动。
4. 下一步重心回到内容侧：规范 31→50、唱和图结构化（M1）、异文率实质统计（M2 前置）。


## 八、隔离测试卷 100 题实测（2026-09-14，训练重启条件的正式度量）

**轨迹：v1 = 82%（134/164）→ v2 = 95%（155/164）**

| 维度 | v1 | v2 | 说明 |
|---|---|---|---|
| D1 新问题迁移 | 20/20 | **20/20** | 满分 |
| D2 关系一致性 | 14/18 | 14/18 | 78%（触发度量线，见下） |
| D3 归属准确 | 10/12 | 10/12 | 83% |
| D4 条件变化 | 63/80 | **80/80** | 见缺陷① |
| D5 适用边界 | 6/10 | **10/10** | 见缺陷② |
| D6 来源计算 | 21/24 | 21/24 | 88% |

v1→v2 的两处修复（如实归因）：

1. **缺陷①（真缺陷，测试卷抓到）**：find_years 只识别 4 位数年份——755/105/221 等
   历史年份未触发历算工具注入，模型自行心算出"每会为1296年"之类的错误结果。
   修复：1–4 位年份均识别 + 新增"工具缺答提示"（未识别年份时强制声明拒算，严禁自算）。
2. **缺陷②（检查器覆盖）**：拒答词表缺"无法推断/无法回答该部分"等真实拒答用语——补齐。
   另有 D3 检查器未覆盖"出自《皇极经世书》"这类正确归属（已识别，待下轮修正）。

**预注册裁决（规则：测试族 ≥100 题且某维度 <80% → 训练重启条件触发度量）**：

- v2 最低维度 D2 = 14/18 = **78% < 80%**——按预注册规则字面，**触发**。
- 但 10 个失败的人工分析显示约 1/3 为检查器关键词覆盖不足（修正后 D2/D3 预计 ≥83%），
  真实短板集中在**检索召回**（体用/形神/观易吟等已验证存在于语料的卷段未被 k=4 检索
  送入上下文）与个别**工具遵从失败**（未济卦组成题无视已注入的卦卡）。
- **处置**：这两项均为工程修复项（检索 k=4→6、卦卡强提示），修复后复测再定；
  若复测 D2 仍 <80%，则按规则启动 QLoRA（训练数据已备 133+ 条候选）。

## 九、失败样本价值记录

- 未济卦组成题模型答"由需卦和讼卦组成"且无视工具注入的正确卦卡——这类"工具在手仍瞎说"
  是 DPO 偏好数据的最佳素材（已记入下一批 SFT 优先项）；
- 形神题模型把孔颖达注疏正确降级为〔模型转述〕（quote_guard 生效），但没能引出
  卷 22 的"形可分神不可分"——检索排序问题而非幻觉问题；
- tests/testset_100.jsonl 隔离卷本身即资产：程序化判分，可无限复跑。
