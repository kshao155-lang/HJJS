# Codex 反馈对照评估（2026-09-13）

> Codex 就"基于本系统做邵雍思想体系 / 元会运世"与"按邵雍世界观训练模型"给出两份长反馈。
> 本文档逐条对照本仓库现状，裁决：已建成 / 本轮已落地 / 待办（含前置条件）/ 需修正处。

## 一、总评

Codex 的核心判断与本项目实际进展**高度一致，且互相印证**：

- 其"两项第一核心资产"——**经过校勘的原典—注释—规则对照库** 与 **可追溯的元会运世计算引擎**
  ——本项目均已有实质资产：corpus/（道藏本皇极经世 23 卷全书 + 三个对照版本 + 击壤集两版本，
  含版本异文与 OCR 讹字标注）与 huangji/lishu.py（确定性引擎、锚点参数化、全量测试）。
- 其对预测宣称的谨慎（"软件计算正确 ≠ 理论解释正确"）与本项目实验结论
  （治乱与绝对年相位无关，负结果可发表）是同一立场的两种表述。
- 其"四种内容不混写"（原典/注家/计算/推演）原则已被采纳为训练规范 V0 的强制标注体系。

## 三、对 Codex 反馈的三点补充（基于它看不到的仓库实况）

1. **语料独有资产**：本仓库已实现"同书多版本并存"（皇极经世四本、击壤集两本）——
   这正是 Codex 设想的"经典与注释"层的实料，且额外构成平行语料（AIHub 探索 J2 的 M2 方案）。
2. **起算方案分歧有历史实据**：不只是"注家可能不同"——赵友钦原文自带第二方案及其校验点，
   引擎已把它变成可测试的事实（1324=午会10运11世1年，测试断言通过）。
3. **负结果是现成的规范素材**：训练规范的 T05 条目直接引用本项目实验负结果，
   用于约束模型不做无证据的相位预测——这是 Codex"解释边界"维度的实例化。
