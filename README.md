# 皇极经世（HJJS）· 用邵雍的思想训练一个理解世界的模型

> **从一句设问到完整闭环**："用邵雍的世界观，能不能训练一个模型？"
> 本仓库的回答不是一篇论文，而是一整套可复现的系统：
> 语料库 → 历算引擎 → 历史实验 → 结构化验证 → 满分问答系统 → 训练规范与数据流水线。
> 本 README 把全部研发理念与训练哲学事无巨细地写下来——包括每一个失败和每一次自我否定。

## 〇、训练哲学（最初的理念，从未动摇的十条）

### 理念 1：思想体系若不能操作化，就只是文学

邵雍给出的不是感悟，而是一台机器：六十四卦是 **6 比特状态空间**（初爻为最高位，先天序=64−v，
与莱布尼茨 1703 年二进制算术结构同构）；元会运世是 **129,600 = 12×30×12×30 年的多尺度时钟**；
十二消息卦是**单比特翻转的循环状态机**（进位点 32→48→56→60→62→63→31→15→7→3→1→0）；
声音唱和是**组合编码系统**（声 112 × 音 152 → 唱和 17,024 → 通数 289,816,576，全部整数恒等式
在原典层面可机器复算）。所以我们做的第一件事不是写文章，而是把这些变成代码和测试：
`test_huangji.py` 的每一条断言都是哲学主张的机器形式。

### 理念 2："以物观物"是认识论，也是工程学

邵雍："以物观物，性也；以我观物，情也。性公而明，情偏而暗。"（道藏本卷 22）
这条认识论被我们工程化为四个层次：

1. **特征层**：物观模型只许用时、位、数、象（周期相位），人类叙事特征（王朝已行年）
   单独成族对照——两组特征的泛化差异直接检验"性公而明 vs 情偏而暗"；
2. **评估层**：指标只锚外部不变量（史表标签、整数恒等式），禁止模型自评；
3. **数据层**：回答中的每一条古文引文必须回到语料逐字验证（`quote_guard`），
   转述不许冒充原典；
4. **评测层**：评测器本身也要"以物观物"——我们自己的检查器修过 3 个 bug
   （标签后缀不匹配、查错年份、标点口径），评测器犯错和模型犯错同样不可容忍。

### 理念 3：数出于理，违乎理则入于术——供观，不供占

邵雍："天下之数出于理，违乎理则入于术。世人以数而入术，故失于理。"
这是全项目最重要的门禁：**元会运世坐标可以算（供观），事件不可测（不供占）**。
落到系统行为：问答系统被问"预测战争/股票/运势"时必须拒答，并引这句话说明为什么。
这不是免责声明，是训练目标——边界拒答是六维评测的独立维度（D5），写进 SFT 数据。

### 理念 4：软件计算正确 ≠ 理论解释正确

历算引擎算得再准，也不构成"该体系能解释历史"的证据。所以引擎与实验严格分离：
引擎负责确定性换算（双起算方案、逆运算、边界测试），实验负责检验解释力——
而实验给出了**诚实的负结果**：中国四千年治乱与绝对年相位无可学习关系
（物观 0.669 vs 基线 0.681，置换检验同分布；v1 曾报告的"盛世避运末 p≈0.008"
经聚类块置换与窗口族校正后退为 p≥0.13，**属伪独立幻觉**，我们公开撤回）。
负结果与正结果同等呈现——这是对邵雍"数出于理"最好的遵守。

### 理念 5：LLM 管解释，确定性程序管历算

语言模型永远不心算元会运世。问答系统的架构是：检索（BM25+繁简归一）→
**确定性引擎注入**（年份→双方案坐标；卦名→卦卡，全部由 `huangji.lishu` 计算）→
LLM 组织解释并照录工具输出。实测：历算类答案对引擎输出的照录是逐字的（零幻觉）。
换任何一个基座模型，同一规则下的坐标不变——可插拔、可审计。

### 理念 6：语料工程优先于训练

模型答错"《梅花易数》是邵雍写的吗"（0/2）时，第一反应不是训练，而是问：
失败是能力问题还是信息问题？——辨伪知识根本不在语料里，RAG 结构上答不了。
把辨伪工具文件加入语料后，归属题 0/2→4/4，**零训练成本**。
同理"提示词迭代"修复了边界拒答（1/3→3/3）。训练永远是最后手段，见理念 8。

### 理念 7：四类内容强制标注，不可混写

每条数据、每次回答、每份文档，内容性质必须标注其一：
**【原典记述】**（可定位原文）/**【注家解释】**（标注者）/**【规则计算】**（标方案与锚点）/
**【现代推演】**（标依据）。"邵雍说过 X"与"我们借邵雍解释现代 Y"是不同性质的陈述。
托名作品（《梅花易数》等）与衍生文献单独分层（corpus/04、06），标签照抄不得改写。

### 理念 8：训练是最后手段，且分岔点必须预注册

提前写下裁决规则，到点执行，不许事后挪门柱：

- 训练规范 50/50 ✅ + SFT 示范 500 条（进行中）+ 隔离测试 100 题（进行中）→ 才许谈训练；
- RAG 基线六维 ≥ 目标 → 不训练。**实测 RAG 满分（29/29），QLoRA 正式暂缓**；
- 训练重启条件（已预注册）：测试族 ≥100 题且某维度 <80%；或新增"长篇综合分析"
  维度后不达标；或诗歌生成立项。
- 这条哲学的出处是我们自己踩过的坑：v1 曾把"12 个盛世区段"当 12 次独立试验——
  **没有预注册的推断，研究者自由度会替你制造任何你想要的显著**。

### 理念 9：一切断言必须可复算——包括古文引文

- 卦序/二进制同构/消息状态机/历法锚点：Python 断言（测试全绿才算陈述成立）；
- 声音唱和数链：体数 160/192 → 用数 112/152 → 唱和 112×152=17,024 →
  通数 17,024²=289,816,576，**每一步先定位原文（卷 21）再做算术**，11/11 通过；
- 律块结构：16 声组×7 行=112、16 音组×{9,12,5} 行=152，逐块恒等式 32/32；
- 卦配规律：置换检验 p=0.00005（卦配是律节结构的确定函数，坎艮巽各 48 行）；
- 引文：训练规范 50 条，每条先 grep 定位语料，再写条目；AI 生成的候选引文
  逐字校验不合格即打回（流水线首日就抓住 4 条跳读拼接的引文）。

### 理念 10：支持与批评一起纳入

赵友钦（元）《革象新书》评邵雍"世人多信其说，以愚观之，实不可准"——批评原文
全文入库（corpus/05），与支持材料同等呈现。而讽刺的是，正是赵友钦给出的第二起算方案
（夏禹八年甲子当午会初）成了我们引擎的第二个测试锚点（泰定甲子 1324=午会 10 运 11 世 1 年，
测试断言分毫不差）。**批评者让系统更坚固。**

## 二、评测轨迹（每一分的来源如实归因）

```
76%（16/21） 首测——检查器自身有 2 个 bug（评测器也要以物观物）
83%（24/29） 辨伪文件入语料 → 归属题 0/2→4/4（语料工程 > 训练）
90%（26/29） 预测类问题检测+边界指令前置 → 拒答修复（提示词工程）
93%（27/29） 检查器语料规范化补收 .md（陷阱句回声不再误判）
100%（29/29）quote_guard：去标点比对+近似引文校准为语料原文+转述降级
```

六维定稿：新问题迁移 4/4 · 关系一致性 6/6 · 归属准确 4/4 · 条件变化 7/7 ·
适用边界 3/3 · 来源与计算 5/5。
诚实声明：12 题是小测试族；满分属于"基座+语料+提示词+后处理"整体；扩到 100 题后
预计仍有长尾失败——所以训练重启条件已经预注册。

## 四、数据生产纪律（SFT 流水线的红线）

1. AI 只做候选生成（audit=pending），人工审核定稿（approved/rejected）；
2. 引文必须逐字命中语料——流水线首日就拦下 4 条跳读拼接（AI 不许替邵雍说话）；
3. 历算类答案只许照录引擎输出，不许模型自行计算；
4. 【现代推演】不得混写为【原典记述】；
5. 不用已发生事件反推"验证"（选择后推断禁令）。

批次 1：115 条候选（卦象 64 · 概念 24 · 消息卦 12 · 归属 7 · 历算 4 · 边界 4），
自动质控 115/115。目标 500 条 + 测试族 100 题 → 触发预注册的训练分岔点复审。

## 五、模型基座立场

需要且只需要一个：**Qwen2.5-7B-Instruct**（Apache-2.0，权重已就位并校验 14.19GB/339 张量）。
不从零预训练（语料量级差 5 个数量级），排除 70B（本机 A100-40GB 性价比不允许）。
训练用 QLoRA（本机可跑，10–12GB 显存），可选 DPO——但只按理念 8 的分岔点启动。

## 八、诚实边界（本仓库不宣称的事）

- 不宣称邵雍体系"能预测历史"——我们的实验结论相反，且已公开撤回自己的边缘发现；
- 不宣称六维满分等于通用能力——测试族仅 12 题，扩容是预注册重启条件之一；
- 不宣称复现了历史邵雍的判断——训练目标是"邵雍思想框架下的领域推理模型"；
- 古籍 OCR 存在讹字，引用原文请核对影印本（corpus/README 有详单）；
- 《梅花诗》《铁板神数》系托名，本库不收；《梅花易数》收存但标注托名。
