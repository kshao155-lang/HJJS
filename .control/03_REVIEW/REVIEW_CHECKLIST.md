# REVIEW CHECKLIST · 复核清单

> 项目：皇极经世　|　类型：通用研究

每轮分析的复核体系按下列维度逐项过；发现问题→写入 `ERRATA.md`。

- [ ] **事实真实**：关键事实是否可核验
- [ ] **逻辑一致**：推理是否自洽
- [ ] **证据可追溯**：结论是否都挂得上来源
- [ ] **数据正确**：数字/计算/口径
- [ ] **过度声称**：结论是否超出证据
- [ ] **捷径风险**：是否走捷径/省略核验

## 通用红线
- [ ] 所有事实/数字/引用是否真实可核验（无编造）
- [ ] 是否存在为达标走捷径（硬编码、挑数据、藏负结果）
- [ ] 结论是否未超出证据强度（无过度声称）
